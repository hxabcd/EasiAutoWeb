# 开始使用

## 首次配置

1. 解压并运行 EasiAuto，进入 **设置界面**
2. 在登录设置中选择一种[登录方式](/docs/app/login-methods)，并填入你的希沃账号信息
3. 保存设置后，即可手动触发一次登录测试

## 登录方式怎么选

如果你不确定选哪种登录方式，可以参考以下建议：

- **固定位置**：配置最简单，适合分辨率和缩放固定不变的机器
- **图像识别**：适应性强，不怕界面元素位置变化，但需要完整版
- **自动定位（UI Automation）**：直接操作界面元素，不论分辨率和缩放，输入框被遮挡也不影响
- **进程注入**：能力最强的方案，具体限制见[登录方式详解](/docs/app/login-methods)

## 运行前警告与推迟登录

当 EasiAuto 即将自动执行登录时，会弹出 **运行前警告弹窗**，避免自动运行措手不及。如果你暂时不想登录，可以在弹窗中选择 **推迟登录**，稍后再执行。

## 横幅警示

登录执行期间，屏幕上会显示醒目的 **横幅警示**，提醒他人不要操作一体机。横幅内容支持高度自定义，可以在设置中调整。

## 更多技巧

- **单次跳过**：临时跳过一次自动登录
- **错误重试**：登录失败时自动重试
- **兼容模式**：遇到兼容性问题时可尝试开启
