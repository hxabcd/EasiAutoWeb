# 下载与安装

## 系统要求

在下载前，请确认你的设备满足以下条件：

- **操作系统**：Windows 10 及以上版本
- **希沃白板**：已安装希沃白板（EasiNote），并已完成基础配置
- **ClassIsland**（可选）：如需在上课时自动登录，推荐同时安装 [ClassIsland](https://www.classisland.tech) 并配置好时间表和课表

## 选择版本

EasiAuto 提供 **稳定版** 与 **测试版** 两个更新通道，每个通道都有 **完整版** 与 **精简版** 两种打包：

| 版本 | 适合人群 |
| --- | --- |
| 稳定版 · 完整版 | 大多数用户，功能完整、经过充分测试（推荐） |
| 稳定版 · 精简版 | 不需要图像识别登录、追求更小体积的用户 |
| 测试版 | 想要尝鲜最新功能、愿意反馈问题的用户 |

前往[下载页面](/download)获取最新版本，历史版本可在[版本历史](/download/versions)页面查看。

## 安装

EasiAuto 是 **便携版软件，无需安装**，但需要注意：

1. 将下载得到的压缩包 **完整解压** 到一个固定文件夹（例如 `D:\EasiAuto`）
2. 直接运行解压出的主程序即可

:::warning
请不要直接在压缩包中运行程序，也不要遗漏压缩包内的任何文件，否则软件无法正常工作。
:::

## 验证文件完整性

每个发布渠道都提供 SHA256 校验和。下载完成后，可以使用以下命令校验文件是否完整、未被篡改：

```powershell
Get-FileHash .\EasiAuto.zip -Algorithm SHA256
```

比对输出的哈希值与下载弹窗中显示的是否一致。
