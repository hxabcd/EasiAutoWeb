# 自动更新

EasiAuto 内置自动更新功能，允许从互联网检查、下载并自动安装更新，及时接收功能增强和问题修复。

## 更新通道

| 通道 | 说明 |
| --- | --- |
| 稳定版 | 经过充分测试的正式发布，默认通道 |
| 测试版 | 包含最新功能的预发布版本，可能存在不稳定因素 |

可以在设置的「更新」页面中切换更新通道。

## 更新流程

1. EasiAuto 会定期检查新版本（也可在更新页面手动检查）
2. 发现新版本后，可查看更新日志与亮点功能
3. 确认后自动下载并安装更新
4. 部分重要更新会提示确认后再安装

## 手动更新

如果自动更新不可用，也可以前往[版本历史](/download/versions)页面或 [GitHub Releases](https://github.com/hxabcd/EasiAuto/releases) 手动下载最新版本，解压覆盖原有文件即可。
