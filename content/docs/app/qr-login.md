# 二维码登录

EasiAuto（测试版）支持 **二维码登录**：像手机端希沃白板一样，使用手机扫码即可完成登录，无需在软件中保存账号密码。

## 首次使用

:::warning
二维码登录功能首次使用时，需要以 **管理员权限** 运行 EasiAuto 以替换相关 DLL 文件。
:::

1. 以管理员身份运行 EasiAuto
2. 在登录设置中选择「二维码登录」
3. 等待程序完成首次初始化（替换 DLL）
4. 此后即可正常使用，无需每次都以管理员权限运行

## 日常使用

配置完成后，触发登录任务时 EasiAuto 会自动调起二维码登录流程，与手机端扫码登录的体验一致。

:::info
二维码登录目前随测试版发布。如需使用，请在[下载页面](/download)选择测试版渠道。
:::
