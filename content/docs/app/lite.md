# 精简版说明

:::info
**1.3.0 及以后的版本已移除精简版分支**，统一为单一版本（完整功能）。本页说明仅适用于 1.3.0 之前的版本。
:::

1.3.0 之前的每个版本都提供 **完整版** 与 **精简版** 两种打包。两者功能主体一致，区别在于：

| 组件 | 完整版 | 精简版 |
| --- | --- | --- |
| 固定位置登录 | ✅ | ✅ |
| 自动定位（UI Automation） | ✅ | ✅ |
| 进程注入 | ✅ | ✅ |
| 图像识别登录（OpenCV） | ✅ | ❌ |
| 体积 | 较大 | 更小 |

## 如何选择

- 如果你使用 **图像识别** 登录方式，请下载 **完整版**
- 如果你只用固定位置、自动定位或进程注入登录，**精简版** 体积更小、下载更快

:::info
早期版本的精简版渠道名称为 `no_cv`（无 OpenCV），与现在的 `lite` 渠道含义相同。
:::
