# 登录方式详解

EasiAuto 提供四种登录方案，以适应不同的机型、系统环境与使用习惯。你可以在设置界面中为登录任务选择任意一种。

## 固定位置

在屏幕上的 **固定位置** 模拟鼠标点击与键盘输入，直接操作希沃白板的登录界面。

- **优点**：实现简单、资源占用低、无需额外组件
- **局限**：依赖登录窗口出现在预期位置，分辨率或缩放变化、窗口位置偏移时可能失效
- **适合**：一体机分辨率固定、登录窗口位置稳定的场景

## 图像识别

基于 OpenCV 的 **图像识别** 定位：在屏幕上寻找登录界面中的特征图像（如输入框、按钮），找到后再执行输入。

- **优点**：不依赖固定坐标，窗口位置变化也能正确操作
- **局限**：需要完整版（内含 OpenCV 组件）；极端亮度或缩放环境下识别可能不稳定
- **适合**：窗口位置不固定、但希望保持较高兼容性的场景

## 自动定位（UI Automation）

通过 Windows 的 **UI Automation** 框架直接定位并操作页面元素。

- **优点**：不论什么分辨率、缩放都能胜任，输入框被遮挡也不影响登录，不需要 OpenCV
- **局限**：依赖目标程序暴露的 UI 元素信息
- **适合**：大多数现代希沃白板版本，是通用性最好的方式之一

## 进程注入

将代码注入希沃白板进程内部执行登录。

- **优点**：能力最强，不依赖界面状态
- **局限**：侵入性较高，可能被安全软件拦截；需以合适的权限运行
- **适合**：其他方式均无法满足时的进阶选择

## 如何选择

| 场景 | 推荐 |
| --- | --- |
| 追求稳定省心 | 自动定位（UI Automation） |
| 机器配置低、环境固定 | 固定位置 |
| 窗口位置多变 | 图像识别（完整版） |
| 特殊环境、其他方式失效 | 进程注入 |

此外，测试版还支持[二维码登录](/docs/app/qr-login)——扫码即可完成登录，无需在软件中保存账号密码。
